# B 站换课表：看谁的课，看到第几集换谁

> 结论：**一次只跟一个 UP 主，按阶段换，不并行。**
> 换课的唯一理由是"这个 UP 主在这个知识点上讲得最好"，不是因为"看腻了"。
>
> 集数为 2026-11 检索到的公开数据（部分来自第三方汇总），**BV 号准确，P 序号以你打开时视频标题为准**——
> B 站 UP 主会重剪、加集、分 P，用标题对位比用集数对位可靠。

## 阶段 1（D1–D10）· 黑马上部 P1 → 面向对象结束

**看什么**
- P1–P30：环境搭建、变量类型、运算符、流程控制
- P30–P70：方法、数组、二维数组
- P70–P120：类与对象、封装、继承、多态

**怎么看**
- 1.5 倍速。有 C 语言基础的话，P1–P30 可以用 2 倍速扫过
- 每集开头有一段固定广告（约 10 秒），直接拖过去
- 每章结束关视频重写一遍，写不出来就回看那一章

**换课信号**：能自己写出 `Animal` / `Dog` / `Cat` 三层继承 + 接口实现，就切尚硅谷。

**为什么不选老杜**：老杜 844 集（P1–P159 JDK8 版、P160–P476 JDK13 版、P477–P844 进阶），讲得极细但慢，按每天 4 集要 200 天。他的价值在"掰开揉碎地讲为什么"，适合零基础非科班；你有计算机专业基础，跟着他走等于把 90 天烧在语法上。

---

## 阶段 2（D11–D18）· 尚硅谷宋红康，只取「面向对象深化 + 集合」

**看什么**（用标题找，不数集数）
1. 「面向对象（中）」：继承、重写、super、多态、向下转型
2. 「面向对象（下）」：static、final、抽象类、接口、内部类、**equals / hashCode 重写**
3. 「异常处理」
4. 「集合」：Collection、List、Set、Map、Iterator、泛型、**HashMap 底层（数组+链表+红黑树、扩容、负载因子）**

**看完就停**，不要顺着看 IO 流和网络编程。

**为什么换他**：这三块是面试第一轮的核心考点，尤其是 `equals` / `hashCode` 的约定和 `HashMap` 扩容机制——黑马上部只是演示用法，宋红康会讲源码和设计动机。

**这套课的坑**：总共 717 集（第三方统计 800+），**永远不要想着看完**。宋红康讲得慢，1.75 倍速起步；他是 JDK 8 时代的课，新语法（record、var、switch 箭头）在这里没有，不影响面试。

---

## 阶段 3（D19–D24）· 回黑马，IO + 多线程 + 反射

**看什么**：黑马上部里面向对象之后的章节
- IO 流：File、字节流、字符流、缓冲流、转换流、序列化
- 多线程：Thread、Runnable、线程安全、synchronized、Lock、线程池
- 反射、注解、动态代理（这块快过，知道能干什么就行）

**为什么回黑马**：IO 的乱码问题、多线程的实战案例（下载器、生产者消费者），黑马的代码演示更贴近工作中要写的代码。

---

## 阶段 4（D25–D32）· 老杜 MySQL，整块换人

**看什么**：`BV1fx411X7BD`，从安装配置到
- 建表、约束、增删改查
- 多表查询（内连接、外连接、子查询）
- 索引（B+ 树、聚簇索引、索引失效场景）
- 事务（ACID、隔离级别、MVCC、锁）

**为什么这块必须换老杜**：MySQL 是青岛 Java 岗 JD 里出现率 100% 的技能，也是面试必问。老杜的 MySQL 课是全网公认最好，边讲边敲 SQL，配套 34 道面试题。这一段不要用 Java 课里的附带章节凑。

**验收**：建出 90 天计划里的「岗位库」5 张表（公司、岗位、技能要求、投递记录、面试记录），写 10 条多表查询。

## 阶段 5–6（D33–D40）· 黑马 Maven + 狂神说 MyBatis

| 顺序 | 课程 | 时长 | 看到哪 |
|---|---|---|---|
| Maven | 黑马 `BV1Ah411S7ZE` | 约 3 小时 | 全看 |
| MyBatis | 狂神说 `BV1NE411Q7Nx` | 约 8 小时 | 到动态 SQL 为止 |

狂神说（秦疆）的特点：不讲废话、直接写代码、每集很短。适合"我要赶紧能跑起来"的阶段。他的课录制在 2020–2021 年，版本较老，遇到依赖报错去 MyBatis 官方文档查当前版本号。

---

## 阶段 7（D41–D46）· 狂神说 Spring Boot

`BV1PE411i7CV` 全看。这一套讲完你会：起服务、写 Controller、接数据库、打 Thymeleaf 页面。

**注意**：狂神说的是 Spring Boot 2.x，你后面要用 Spring Boot 3 的话，`javax.*` 要换成 `jakarta.*`——这是唯一的坑。

Spring 的 IOC / AOP **原理**这里不深讲，等 D47 做项目时遇到"为什么注入不进去"再回查尚硅谷《Spring5 框架》`BV1WE411d7Dv` 对应那几集。

---

## 阶段 8（D47–D49）· 项目实战，只看结构

瑞吉外卖 / 苍穹外卖（黑马）挑一个，跟着做到**登录 + 一个业务模块 + 一个列表查询**就停。

**关键动作**：视频里他建什么表你建什么表，但他写的代码你要按自己的需求重写一遍（把"菜品"换成"岗位"，把"订单"换成"投递记录"）。抄一遍等于没学，改一遍才算会。

## 换课的三个铁律

| 铁律 | 说明 |
|---|---|
| **不并行** | 任何时候只跟一个 UP 主。两个课同时开，两套术语体系混在一起，效率砍半 |
| **不为集数焦虑** | 尚硅谷 717 集、老杜 844 集、韩顺平 910 集——谁都不可能看完，只看你需要的段 |
| **用标题对位，不用集数** | UP 主会重剪加集，`BV号 + 章节标题` 才稳定。本表给的 P 序号只作参考 |

## 不在本表里的课（不用看）

| 课程 | 原因 |
|---|---|
| 韩顺平 30 天学会 Java（910 集） | 内容与黑马/尚硅谷高度重叠，集数更多，没必要重复投入 |

| JSP / Servlet 手写课 | 前后端分离时代已淘汰，青岛 JD 不写 |
| Struts2 / Hibernate / EJB | 过时技术栈 |
| GUI（Swing / JavaFX） | 工作不用 |
| Spring Cloud 微服务 | 青岛中小公司用不到，2028 届校招前再说 |
