# 黑马 Java 课程切片表（90 天版）

> 结论：**不要"先把课看完"。** 黑马全套（基础 + Web + 框架 + 项目）约 400 集、200+ 小时，
> 按每天 2 小时看，看完要 100 天以上——90 天计划正好被视频吃光，手上一个项目都没有。
>
> 正确做法：**按 90 天的节点切课程，看一章立刻写一章，视频与代码 1:1 配比。**

默认值：课程按《黑马程序员 Java 从入门到精通（基础 + Web + 框架 + 项目实战）》假定，
集数按该套编排估算；如果你的版本章节名不同，按"知识点"对位，不按集数对位。

---

## 一、三种学法对比

| 学法 | 视频耗时 | 90 天后你手上有什么 | 判断 |
|---|---|---|---|
| 全集通关（先看完再说） | 200h+ | 看完忘一半，无项目，简历空白 | 排除 |
| 纯分片（遇到问题才搜） | 30h | 知识零散，写不出完整项目 | 排除 |
| **阶段切片（本表）** | **约 90h 视频 + 90h 代码** | **2 个能跑的项目 + 能应付面试** | **选这个** |

核心差异：**看视频不是学习，敲代码才是。视频只用来"知道有这个知识点"，能力长在键盘上。**

## 二、三个窗口

### 窗口一：D1–D28（地基）｜约 180 集 / 60 小时

| 顺序 | 章节 | 约集数 | 完成标志 |
|---|---|---|---|
| 1 | Java 基础语法：变量、类型、运算符、流程控制 | 30 | `day01` 四个程序跑通 |
| 2 | 方法与数组（含二维数组） | 20 | 能手写冒泡 + 二分查找 |
| 3 | 面向对象：类/对象、封装、继承、多态、接口、抽象类 | 45 | 写一个 `Animal`/`Dog`/`Cat` 体系 + 接口回调 |
| 4 | 常用 API：String、StringBuilder、包装类、日期、正则 | 25 | 写一个字符串统计工具 |
| 5 | 集合框架：List / Set / Map、泛型、Iterator、Stream | 35 | 用 `HashMap` 统计词频并排序输出 |
| 6 | IO 流：File、字节流、字符流、缓冲流、序列化 | 25 | 写一个日志文件读写工具 |
| 7 | 多线程：Thread、Runnable、线程池、synchronized、Lock | 20 | 写一个多线程下载/统计器 |
| 8 | MySQL：建表、增删改查、多表联查、索引、事务 | 30 | 建出"岗位库"5 张表并写 10 条查询 |

### 窗口二：D29–D49（框架 + 项目一）｜约 80 集 / 25 小时

| 顺序 | 章节 | 约集数 | 完成标志 |
|---|---|---|---|
| 9 | Maven + JDBC 复习 | 15 | `pom.xml` 能拉依赖，JDBC 能连 MySQL |
| 10 | MyBatis / MyBatis-Plus | 20 | 单表 CRUD + 条件查询跑通 |
| 11 | Spring：IOC/DI、AOP、Bean 生命周期 | 20 | 能说清 `@Autowired` 和 `@Bean` 的区别 |
| 12 | Spring Boot：注解、配置文件、拦截器、全局异常 | 25 | 起一个 8080 服务，`/hello` 有响应 |
| 13 | 项目一实战（**只看不抄，按自己需求重写**） | 按需查 | 8 个接口 + Swagger 文档 + 部署地址 |

### 窗口三：D50–D90（Python + 补课 + 面试）

**Java 视频基本停看**，只在遇到具体问题时回查对应那一集。

| 内容 | 处理方式 |
|---|---|
| Python 基础 + Pandas | 另开一套课（黑马 Python 数据分析，只看前 1/3） |
| Redis / JWT | 回查 Spring Boot 那几集 + 官方文档 |
| 八股（JVM、集合源码、MySQL 锁、Spring 原理） | 不看视频，看文字 + 自己做题 |
| LeetCode | 独立线，每天 2 题，不占视频时间 |

## 三、必看 / 快过 / 直接跳

### 必须慢看（每集看两遍，跟着敲）

| 章节 | 为什么 |
|---|---|
| 面向对象：继承、多态、接口 | 面试第一问，也是 Spring 的地基，讲快了你后面全听不懂 |
| 集合：ArrayList / LinkedList / HashMap 底层 + 泛型 | 面试高频，`HashMap` 扩容和红黑树必问 |
| IO 流：字节流 vs 字符流、缓冲流 | 乱码问题全在这里，工作中天天遇到 |
| 多线程：线程池、锁 | 面试必问，也是后端性能的地基 |
| MySQL：多表查询、索引、事务 | 青岛岗位 JD 里 100% 出现，且面试必考 |
| Spring：IOC/DI、AOP、Bean 生命周期 | 框架面试的核心，其他都可以现查 |

### 1.5 倍速过（看一遍，代码跑通就走）

- 语法细节、运算符、流程控制（你有编程基础的话，这部分最快）
- String / StringBuilder / 包装类 / 日期 API / 正则
- Maven 配置、MyBatis 的 XML 写法
- Spring Boot 的配置文件、日志

### 直接跳过（不看不亏）

| 跳过内容 | 理由 |
|---|---|
| GUI（Swing / AWT / JavaFX） | 工作里不用，青岛岗位 JD 一条都没有 |
| JSP / 手写 Servlet / Struts2 / Hibernate | 过时技术栈，2026 年的 JD 已经不写这些 |
| 网络编程 Socket 深入 | 只看 TCP/UDP 概念那一两集，其余跳过 |
| 数据结构与算法课程 | 另开 LeetCode 线，不在视频里学 |
| 设计模式大全（23 种） | D25 后单独花 2 小时看 6 个常用的：单例、工厂、策略、模板方法、代理、观察者 |
| Vue / React 深入 | 只需到"能看懂页面、能改字段"的程度，青岛前端岗极少 |

## 四、每天的节奏（2.5 小时版）

| 时段 | 做什么 | 时长 |
|---|---|---|
| 19:30–21:00 | 看 3–4 集（1.5 倍速，约 25 分钟/集） | 90 min |
| 21:00–21:50 | **关掉视频**，把当天代码从零敲一遍 | 50 min |
| 21:50–22:10 | `git add -A && git commit && git push`，打卡表填当日 | 20 min |

铁律：**当天视频当天敲，绝不"先攒着以后一起练"。**

---

## 五、新手最大的坑（必须避开）

| 坑 | 表现 | 后果 | 解法 |
|---|---|---|---|
| 抄代码当学会 | 跟着视频一行行抄，编译通过就往下 | 一周后从零写全是空白 | 每章结束关视频重写一遍 |
| 追进度不回头 | 一天看 10 集，感觉很快 | 第 29 天做项目时全部推倒重来 | 视频:代码 = 1:1，看多少敲多少 |
| 只看不记 | 看完就忘，不做笔记 | 面试前全忘光 | 每章结束写 3 行笔记进 `docs/` |
| 完美主义卡在一集 | 一个知识点卡 3 天 | 90 天计划崩盘 | 卡超过 40 分钟就跳，标记问题，周末统一问 |

## 六、验收：每章结束时自问 3 句

1. 这个知识点，我能不能不看资料讲清楚？
2. 关掉视频，我能不能从零写出一个能跑的例子？
3. 面试官问"这个你用过吗"，我有没有具体代码可以指？

三句都答"能"，才进下一章；有一句答不上，回去重写代码，不用重看视频。
