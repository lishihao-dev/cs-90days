# 只能寒暑假实习？青岛 Java 路线的时间安排（修正版）

> 前提变更：原方案按"学期内 5 天/周、3-6 个月日常实习"设计，现在改为**只能寒暑假全职**。
> 这个变更不影响 90 天学习计划，但会改掉投递策略的**顺序**。

---

## 一、先说结论

| 判断 | 内容 |
|---|---|
| 寒假去青岛实习 | **基本走不通**。搜到的青岛寒假短期岗全是运营/客服/远程刷单类，没有一家正经 Java 开发 |
| 暑假去青岛实习 | **可行，而且是主战场** |
| 但什么时候投 | **不是 6 月，是 3-4 月**。暑期实习 = 秋招提前批，3-4 月网申高峰，6-8 月入职 |
| "只能寒暑假"会不会影响投递 | **完全不影响**。投递、笔试、面试全在线上，3-4 月你在上课也能投、也能面 |
| 会损失什么 | 学期内的日常实习（亚微、和利时、中荣这批）如果坚持"只能寒暑假到岗"，大概率投不了 |

## 二、寒假为什么走不通（实测）

2026-11 检索青岛"寒假实习 / 短期实习 / 1-2 个月"，结果如下：

| 岗位 | 公司 | 实际内容 | 能不能算 Java 实习 |
|---|---|---|---|
| 账号运营（远程实习） | 申米 | 内容策划、账号运营、提交数据报表 | 不能，纯运营 |
| 信控管理储备 | 京东 | 催收团队管理支持、业务指标分析 | 不能，金融贷后 |
| 运维实习生 | 青岛易链供应链 | 办公设备维护、路由器交换机、综合布线 | 不能，桌面运维 |
| AI 产品实习生（数据看板） | 海尔·万链生态圈 | 数据看板搭建、AI 工具、SQL、ECharts | **勉强算**，偏产品/数据，非 Java 后端 |

原因很简单：**实习的工期决定门槛。** 寒假满打满算 6 周，中间还有春节，实际能到岗 3-4 周。企业招实习生要投入带教成本，3-4 周刚上手就走了，所以正规公司不在寒假放开发岗。愿意放的都是"不需要培养、当天能上手"的活。

## 三、暑假实习的真实机制（这是关键）

很多人以为"暑假实习"就是"放暑假了去找个实习"。实际是两套完全不同的东西：

| 类型 | 暑期实习（Summer Intern） | 暑假散招实习 |
|---|---|---|
| 对象 | 次年毕业的学生（2028 届 → 2027 年暑期） | 不限年级 |
| 性质 | 大厂/国企的**秋招提前批**，核心业务岗 | 日常实习生，缺人就招 |
| 投递时间 | **2-3 月开放，3-4 月高峰** | 6 月放假前后 |
| 流程 | 网申 → 笔试 → 群面/单面 → HR 面，跟秋招一样 | 流程短，基本"今天面明天到岗" |
| 转正 | **有明确转正通道**，干得好直接给秋招 offer | 少数有，多数只给实习证明 |
| 门槛 | 高，看项目、竞赛、实习经历 | 低，0 经验可投 |

**你要的是第一种。** 它 3-4 月投、6-8 月干、8-9 月出转正结果——时间点和你"只能寒暑假"完全不冲突。

## 四、修正后的时间轴（2026-11 → 2027-11）

| 时间 | 阶段 | 你要做什么 | 是否影响上课 |
|---|---|---|---|
| 2026-11-19 → 2027-01-10 | 学期内 | 90 天计划 D1–D53：Java 基础 → 框架 → 项目一 | 不影响，每天 2.5h |
| **2027-01-10 → 2027-02-25** | **寒假（约 6 周）** | **项目一收尾 + 项目二开工 + 简历初稿 + 八股第一轮** | 全职投入，每天 6h |
| 2027-02-25 → 2027-03-31 | 学期内 | **暑期实习第一批投递（线上）** + 项目二上线 + 八股第二轮 | 不影响，投递只花晚上 |
| 2027-04-01 → 2027-05-31 | 学期内 | 笔试 + 面试（**全部线上/周末**）+ 复盘补短板 | 不影响 |
| 2027-06 | 学期末 | offer 确认，谈入职时间（6 月底或 7 月初到岗） | — |
| **2027-07 → 2027-08** | **暑假** | **暑期实习在岗 8 周，争取转正** | 全职 |
| 2027-09 → 2027-11 | 秋招 | 实习转正 + 外部投递双线 | 大四上，课少 |

**注意 2027-02-25 到 2027-03-31 这一个月**：这是全年最关键的一个月，也是唯一需要"学期内"做的事。但投递只是填表、上传简历，笔试面试都在线上或周末，不占白天。

## 五、三种实习形态，你只能选哪种

| 形态 | 到岗要求 | 你能不能用 | 说明 |
|---|---|---|---|
| 日常实习（亚微、和利时、中荣、九麒） | 5 天/周，3-6 个月 | **部分能用** | 如果公司接受"每周 3 天 + 周末补"或"远程"，可以试；严格要求 5 天/周的不行 |
| 暑期实习（大厂/国企提前批） | 7-8 月全职 8 周 | **完全能用** | 这是你的主战场 |
| 暑假散招实习 | 6-8 月，缺人就招 | **能用但质量低** | 保底选项，别当主力 |

**建议动作**：投亚微、和利时、中荣时，简历注明"**可保证 2027 年 7-8 月全职，学期内可每周 X 天到岗/远程**"。20-99 人的小公司对"每周 3 天"的接受度比大厂高，这一句话能救回好几个投递。

## 六、唯一值得试的寒假岗：海尔 AI 产品实习（数据看板）

| 项 | 内容 |
|---|---|
| 公司 | 海尔·万链共享生态圈 / 生物医疗平台 / 数智科研产业 |
| 岗位 | AI 产品实习生（数据看板与管理方向） |
| 时间 | 2026-11-20 ~ **2027-04-01**，5 天/周，招 1 人 |
| 要求 | 本科在读，有前后端基础、SQL、ECharts/AntV 或大模型 API，会用 Cursor/Claude |
| 为什么匹配 | 你 D50–D90 的项目二就是"青岛岗位分析看板"，技术栈完全重合（SQL + 可视化 + AI 工具） |

这条的价值不在"Java 实习"，在于：**它是唯一一条覆盖寒假、且和你项目二同源的真实岗位**。投它的成本是半小时，进面就当练手，进了就当寒假有事干。

## 七、寒假 6 周怎么用（替代"去实习"）

| 周 | 内容 | 产出 |
|---|---|---|
| W1–W2 | 项目一收尾：补接口、写 Swagger 文档、部署到服务器 | 能在线打开的链接 |
| W3–W5 | 项目二开发：数据采集 → Pandas 清洗 → Streamlit 看板 | GitHub 上有 v1.0 |
| W5 | 简历初稿（后端版 + 数据版两份） | 1 页 PDF |
| W6 | 八股第一轮（Java 基础 + 集合 + MySQL） | 100 问答对，能答 60 条 |

寒假这 6 周做完，3 月投暑期实习时你手上有：两个项目 + 3.5 个月连续提交记录 + 一份定稿简历。这是"三无学生"能拿出的最好牌面。

## 八、投递密度：这是最容易被忽略的一条

牛客上的技术岗投递经验：**50~100 份简历是常态，只投 5~10 家基本等于没投。**

青岛本地能投的 Java 岗有限，所以必须外溢：

| 池子 | 家数 | 说明 |
|---|---|---|
| 青岛本地（亚微、和利时、中荣、九麒、聚城、软控、百度青岛） | 7–10 | 主投 |
| 济南 / 潍坊 / 淄博 / 郑州（亚微的 JD 本身就覆盖这些城市） | 10–15 | 外溢第一批 |
| 远程实习（不少中小公司接受异地远程） | 5–10 | 外溢第二批，正好匹配"只能寒暑假"的约束 |
| 大厂暑期实习（不限城市，线上笔面） | 10–20 | 冲刺，进面就是赚 |

总数 35–55 家，这是能拿到 3–5 个 offer 的最低投递量。
