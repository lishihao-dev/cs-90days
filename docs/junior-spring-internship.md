# 你是第几届 + 大三下学期怎么实习

_2026-11-19 更新。基于"2026 年 11 月读大三上"这一前提推算。_

## 一、届数：2028 届，不是 2027 届

按学年倒推，四年制本科只有一个答案：

| 时间 | 你在大几 | 学年 |
|---|---|---|
| 2024-09 → 2025-06 | 大一 | 2024–2025 |
| 2025-09 → 2026-06 | 大二 | 2025–2026 |
| **2026-09 → 2027-06** | **大三（你现在）** | 2026–2027 |
| 2027-09 → 2028-06 | 大四 | 2027–2028 |
| **2028-06** | **毕业** | → **2028 届** |

"届"=毕业年份，不是入学年份，也不是当前年级。2028 届的定义是"2027 年 9 月至 2028 年 7 月毕业的在校生"，
现在读大三、研二的都属这一届。

### 为什么你会以为自己是 2027 届

| 常见混淆 | 实际含义 |
|---|---|
| "我是 2024 级" | 入学年份 → 2024 级 = 2028 届 |
| "我是 2027 届" | 毕业年份 → 2027 届 = 2023 级，现在应该读**大四上**，不是大三 |
| "我大三，所以 2027" | 把"大三结束的年份"当成毕业年份，少算了一年 |

**自查两处，30 秒出结果：**

```powershell
# 不用命令，看两个东西就够
# 1) 学信网 https://www.chsi.com.cn → 学籍查询 → "预计毕业日期"
# 2) 学生证内页 / 教务系统个人信息页的"年级"和"学制"
```

- 学信网写 **2028-06-30** → 2028 届（大概率）
- 学信网写 **2027-06-30** → 2027 届（专升本 3+2、提前毕业、或你其实是 2023 级在读大四）

### 这个差别决定哪些岗能投

| 岗位 | 限届要求 | 2028 届能不能投 |
|---|---|---|
| 普联软件 Java（财务信息化） | "2027 年毕业的在校学生" | ❌ 不符，硬卡 |
| 中荣信科 Java 实习 | "2027 届" | ❌ 不符 |
| 兰剑智能 Java 实习 | "仅限 27 年毕业" | ❌ 不符 |
| 山东亚微软件 Java 实习 | 只写"本科及以上、计算机相关" | ✅ 可投 |
| 青岛和利时 Java 实习 | 只写"本科" | ✅ 可投 |
| 山东极飞 Java 后端 | "2026、2027 届及往届" | ⚠️ 未排除 2028，可问 |
| 百度金融 AI 组 Java 实习 | "统招本科及以上在校生" | ✅ 可投 |
| 中业顺诚（远程）Java 全栈 | 只写"在校" | ✅ 可投 |

**修正**：之前那版《普联匹配度分析》按 2027 届写的（进面 70%–80%），前提不成立。
按 2028 届重新算：现在投这条岗进面 10%–15%，2027 年 3 月普联开 2028 届通道后回到 50%–60%。

|---|---|---|---|
| 中业顺诚科技（青岛黄岛·国贸大厦） | Java 全栈实习生 **Remote** | 月薪 ¥5000、可转正；Spring Boot + JPA + AWS、React + TS | BOSS 上"半年前活跃"，**需先私聊确认在招** |

## 四、三个必须知道的坑

**1）现在投"2027 届"的岗 = 白投。** 普联、中荣、兰剑都写死了届数，HR 第一层就筛掉。
不要在 11 月浪费投递次数，把弹药留到 2027 年 3 月。

**2）"大三下就去上班"这条路在青岛走不通。** 本地 5 天/周的日常实习占 80%，
剩下能谈的只有 3–4 家。硬要学期内上班，最优解是远程，其次是每周 3 天，不是换城市。

**3）暑期实习的机会数量是日常实习的 5 倍以上。** 大厂/国企的暑期实习提前批按 2028 届招，
一次开放几百上千个 HC；青岛本地的日常实习全加起来不到 20 个。所以重心必须是 3 月的提前批，
不是 11 月的日常实习海投。
