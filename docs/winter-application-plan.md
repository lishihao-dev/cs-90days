# 寒假投递作战表（2026-12 → 2027-03）

> 结论：寒假**可以投、也应该投**，但不要把"寒假到岗"当作投递前提。
> 投递动作和到岗时间是两件事，卡住你的从来不是"我只有寒暑假"，而是"我要求立刻到岗"。

---

## 一、先分清三种实习，只有第三种能救你

| 类型 | 到岗要求 | 寒假能不能走通 | 说明 |
|---|---|---|---|
| A. 寒假短期实习（1 个月） | 12 月底—2 月初立即到岗 | **基本走不通** | 扣除春节实际到岗 3–4 周，企业带教成本收不回，正规公司不放开发岗 |
| B. 日常实习（3–6 个月，5 天/周） | 尽快到岗，连续 3–6 个月 | **部分走通** | 20–99 人小公司可谈"寒假全职 + 开学后每周 2–3 天/远程" |
| C. 暑期实习提前批（2027-07 到岗） | 2027 年 7–8 月全职 8 周 | **完全走通，且是主战场** | 2–4 月网申，线上笔面，与上课零冲突 |

**正确动作**：寒假把 B 谈成"寒假上岗 + 开学续远程"，同时把 C 的投递全部做完。
不要去找 A，A 这个品类在青岛基本不存在（真实检索结果里全是运营、催收、桌面运维）。

## 三、简历上必须写的一句话（决定 80% 的回复率）

不要写"仅寒假可实习"。写这个：

```
可到岗时间：2027-01-12 起寒假全职（连续 5–6 周），开学后可每周 2–3 天到岗或远程，
可持续至 2027-08，暑期可全职 8 周。
```

理由：
- 招聘方看到"3–4 周"直接拒；看到"能持续到 8 月"才会约面。
- 20–99 人公司的技术负责人对"每周 2–3 天/远程"接受度远高于大厂，这句话就是给小公司看的。
- 面试时被问"你能待多久"，答"寒假全职起步、开学不断线、暑假全职"，比"只能寒暑假"高一个档。

## 五、投递密度（不能省）

青岛本地 Java 岗总共 7–10 家，只投本地必死。按这个池子投：

| 池子 | 家数 | 说明 |
|---|---|---|
| 青岛本地 | 7–10 | 上面的名单 |
| 济南 / 潍坊 / 淄博 / 郑州 | 10–15 | 亚微 JD 本身就覆盖这几个城市 |
| 远程实习 | 5–10 | 匹配"学期内不能全职"的条件 |
| 大厂/国企暑期提前批 | 10–20 | 线上笔面，不限城市 |

合计 **35–55 家**，这是拿到 3–5 个面试、1–2 个 offer 的最低投递量。

## 六、三个必须接受的现实

1. **寒假拿到"能写进简历的开发实习"，概率大约 20%–30%**（基于岗位数量少 + 到岗周期短）。不是零，但别把宝押在这。
2. **寒假真正的收益是"提前把投递链跑通"**：简历被打回几次、面试被问懵几次，这些在 3 月高峰期之前发生，比寒假拿到 offer 更值钱。
3. **决定性窗口还是 2027 年 3 月**：暑期实习提前批 2–4 月开，2028 届的所有人都在那一个月挤。寒假做的所有事，都是为了让 3 月那一个月你手上有两个项目 + 一份被打磨过的简历。
